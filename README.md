# EksporSiap MVP

Aplikasi backend native PHP untuk mendukung sistem EksporSiap, menggunakan arsitektur MVC sederhana dan PostgreSQL sebagai database.

## Cara Menjalankan
1. Pastikan Docker dan Docker Compose sudah terinstal.
2. Jalankan perintah `docker-compose up` di terminal pada direktori proyek ini.
3. Akses aplikasi melalui browser pada alamat `http://localhost:8000`.
